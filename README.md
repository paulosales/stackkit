# StackKit DevStudio 🚀

> Suíte moderna de ferramentas para desenvolvedores inspirada no GeraDev, com layout Studio inovador, abas multitarefa e execução 100% no cliente.

## 📦 Como Executar Localmente

```bash
# 1. Instalar as dependências
npm install

# 2. Iniciar o servidor de desenvolvimento Vite
npm run dev

# 3. Compilar para produção
npm run build
```

## ✨ Funcionalidades

- **38 Ferramentas completas** organizadas em 7 categorias (Brasil, Geradores, Formatadores, Conversores, Encode/Decode, Rede, Utilidades).
- **Suporte oficial aos padrões brasileiros**: CPF, CNPJ (numérico e alfanumérico), RG SSP, Gerador de PIX (QR Code e Copia e Cola EMV), Gerador de Pessoa e Cálculo de Hora Extra CLT.
- **Barra de Abas Multitarefas**: Abra várias ferramentas simultaneamente e alterne entre elas sem perder dados.
- **Paleta de Comandos Global (`Ctrl + K` / `Cmd + K`)**: Busque e acesse qualquer utilitário instantaneamente pelo teclado.
- **Tema Escuro & Claro**: Alternância suave e persistida no navegador.
- **Bilingue**: Suporte completo a Português e Inglês.
- **100% Seguro & Offline**: Todos os cálculos, formatações e hashes rodam no navegador com Web Crypto API e APIs nativas sem envio de dados a servidores.
